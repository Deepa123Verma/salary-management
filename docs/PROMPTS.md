# Prompts used (summarised)

1. "Here is the assessment email. Help me write a one-page requirements document and tell me which Ruby/Rails version to install."
2. "Which database should I use for 10,000 employees and a take-home assessment?"
3. "Write the spec for Employee validations first (TDD). Give me hints, I want to write the model myself."
4. "Add scopes for filtering by country, department, status and a search scope."
5. "Request spec and controller for GET /api/v1/employees with pagination, filters and a per_page cap."
6. "CRUD endpoints with proper status codes (201, 404, 422, 204)."
7. "A SalaryInsights service: country stats with median, department payroll, job title breakdown, salary distribution bands."
8. "A deterministic seeder for 10,000 employees using insert_all in batches."
9. "React UI with MUI: employees table (search, filters, pagination), add/edit dialog, insights page with charts."
10. "How do I deploy the Rails API (Docker, SQLite) and the React app on Render, including CORS?"

Debugging prompts were the failing test output or the deploy logs pasted as-is.
